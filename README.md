# Исследование вероятности выполнения заявок логистической компанией

## Цель исследования

Цель проекта — на основе методов интеллектуального анализа данных исследовать факторы, влияющие на выполнение заявок на железнодорожные перевозки, и разработать модель машинного обучения для прогнозирования вероятности выполнения заявки, включённой в заявочную компанию.

Логистическая компания ежедневно получает заявки на транспортировку товаров между железнодорожными станциями. В процессе обработки заявки могут изменяться станции отправления и назначения, планируемая дата перевозки, количество вагонов, величина контрибуции и другие характеристики. Кроме того, заявка может быть перенесена на другую дату или отменена.

В конце каждого месяца сформированная заявочная компания передаётся в отдел оптимизации, который составляет расписание движения составов с учётом поступившего объёма перевозок. Основная задача проекта заключается в выявлении закономерностей, позволяющих оценить вероятность выполнения конкретной заявки.

## Данные и предметная область

В качестве исходных данных используется информация о формировании заявочных компаний за период с **01.01.2023 по 30.09.2023**.

Данные содержат историю изменений каждой заявки: от момента её регистрации до окончательного закрытия. Для одной заявки может существовать несколько редакций, отражающих изменения, внесённые операторами в различные моменты времени.

В исходном наборе представлены следующие характеристики:

- **Идентификатор погрузки** — уникальный номер заявки в системе;
- **Дата редактирования** — дата внесения изменений в заявку;
- **Версия погрузки** — номер редакции заявки;
- **Оператор** — сотрудник, осуществлявший редактирование;
- **Дата отправления** — планируемая дата перевозки;
- **Дата отправления факт** — фактическая дата отправки;
- **Учетное направление** — тип перевозки;
- **Кластер назначения и кластер отправления** — региональные характеристики направления перевозки;
- **Код назначения и код отправления** — железнодорожные станции, между которыми осуществляется перевозка;
- **Количество вагонов** — планируемый объём перевозки;
- **Контрибуция** — прибыль компании от выполнения перевозки;
- **Идентификатор переноса** — итоговый статус заявки: выполнение, перенос или отмена.

Особенностью данных является наличие нескольких записей для одной заявки. Это позволяет не только анализировать итоговые характеристики перевозки, но и исследовать историю изменений, которые могли повлиять на результат её выполнения.

## Основная задача машинного обучения

В рамках проекта рассматривается задача классификации заявок по результату их выполнения.

Целевая переменная формируется на основе итогового статуса заявки. Основной интерес представляет определение вероятности того, что заявка будет выполнена, а не перенесена или отменена.

Для решения задачи предполагается использовать исторические характеристики заявок, включая направление перевозки, количество вагонов, контрибуцию, планируемые даты и особенности изменения заявок в процессе их обработки.

Особое внимание уделяется формированию признаков на основе истории редакций. Например, могут рассматриваться количество изменений заявки, частота корректировок, изменение планируемой даты отправления и динамика контрибуции.

Результатом моделирования должна стать оценка вероятности выполнения заявки, которую потенциально можно использовать для поддержки принятия решений при формировании заявочной компании и планировании железнодорожных перевозок.

## Структура проекта

Работа представлена несколькими отдельными файлами, каждый из которых соответствует определённому этапу выполнения проекта. Такое разделение позволяет последовательно рассматривать исходные данные, их подготовку, исследование закономерностей и построение моделей машинного обучения.

В рамках проекта рассматриваются следующие этапы:

1. **Загрузка и первичное изучение данных** — знакомство с исходным набором, анализ структуры таблицы, типов переменных и основных характеристик данных.
2. **Предобработка данных** — обработка пропусков, дубликатов, преобразование признаков и подготовка аналитической выборки.
3. **Исследовательский анализ данных** — изучение распределения заявок по направлениям, датам, количеству вагонов, контрибуции и итоговым статусам.
4. **Формирование признаков** — создание дополнительных характеристик на основе истории изменений заявок и их редакций.
5. **Построение моделей машинного обучения** — обучение и сравнение алгоритмов классификации для прогнозирования результата выполнения заявки.
6. **Оценка качества моделей** — анализ метрик классификации, сравнение результатов и определение наиболее подходящего подхода для решения поставленной задачи.

## Итоги и практическая значимость

Проект направлен на применение методов интеллектуального анализа данных к задаче повышения эффективности планирования железнодорожных перевозок.

Использование исторической информации о заявках позволяет выявить характеристики, связанные с вероятностью их выполнения, а также оценить влияние изменений, вносимых операторами в процессе обработки.

Разработанная модель может стать инструментом предварительной оценки заявок при формировании заявочной компании. Полученные вероятности потенциально позволят выявлять заявки с повышенным риском переноса или отмены и учитывать эту информацию при планировании перевозок.

Проект выполнен в рамках учебной дисциплины **«Методы и средства интеллектуального анализа данных»** в качестве практической работы по применению методов анализа данных и машинного обучения к реальной прикладной задаче логистической отрасли.
